This is an Example of use of donutsql SDK

## Getting Started

First, run the development server:

```bash
npm run dev
# or
yarn dev
# or
pnpm dev
# or
bun dev
```

## Install donutsql

```bash
npm install donutsql
# or
yarn add donutsql
# or
pnpm add donutsql
# or
bun add donutsql
